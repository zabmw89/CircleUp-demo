# Features

## Authentication & Accounts

- User registration
- User login
- Password hashing with `bcryptjs`
- JWT authentication
- Protected API routes
- Profile management
- Profile avatar uploads
- Account-specific content management

## User Profiles

Profiles support:

- Username
- Full name
- Biography
- Avatar
- Location
- Website
- Followers
- Following
- Follow / unfollow
- User search

## Posts

Users can:

- Create text posts
- Attach images
- Edit their own posts
- Delete their own posts
- View post details
- Browse a global feed
- Browse user-specific content
- Highlight hashtags
- Detect URLs

## Social Interactions

The application supports:

- Like / unlike
- Like counters
- Comments
- Comment editing
- Comment deletion
- Following-based feeds
- Follower/following relationships

## User Interface

The frontend includes:

- Responsive desktop layouts
- Tablet-friendly layouts
- Mobile layouts
- Light theme
- Dark theme
- Glassmorphism-inspired visual design
- Toast notifications
- Mobile-friendly navigation
- Reusable interface components

## Demonstrated Workflows

The screenshots in this showcase highlight the following user journey:

```text
Registration
    ↓
Login
    ↓
Social Feed

    ↓
Interact with Posts
```
